# ResNet-50 Models in PyTorch

Notebooks on PyTorch basics and image classification with ResNet-50.

## Notebooks

- `Pytorch_resnet-50.ipynb`: tensors, loading datasets with `ImageFolder`, visualising and customising a dataset
- `ResNet-Image_classification.ipynb`: building ResNet (including ResNet-50), then training and testing it on images

## Built with

Python, PyTorch, torchvision, Matplotlib.

## How to run

Open the notebook in Jupyter (or VS Code) and run the cells from top to bottom.
